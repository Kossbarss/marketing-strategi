# Довільні дошки і розкладка

Перед `create({type:'board', data:{items}})` — **обовʼязково** `how_to('board')`. Для позиціонування — `how_to('positioning')`.

## Коли board

- Відтворити скетч / фото дошки / рукописні нотатки.
- Потрібні абсолютні позиції.
- Кілька різних діаграм на одній дошці (стратегія: mind map + воронка + таблиця + kanban).

## Items (snake_case!)

`{type: "text"|"shape"|"note"|"conn"|"icon"|"link", text, x, y, temp_id, shape_type, font_size, color, from_id, to_id, icon_name}`. `text` підтримує markdown. `conn` — лише для стрілок, що реально є у джерелі.

## Кілька діаграм на дошці

1. Перший `create` — без координат, запамʼятай bbox з відповіді.
2. Далі — `placement: {relative_to: <bbox>, direction: "right"|"below", gap: 100}`.
3. Сітка: праворуч для однорівневих, нижче — для наступного розділу.
4. Заголовки розділів: `edit` → `{"op":"add","type":"text","text":"# Воронка","font_size":"l1"}` над діаграмою, згрупуй через `{"op":"group","ids":[...]}`.

`placement` і `x/y` взаємовиключні. Без координат обʼєкти самі стають нижче існуючого вмісту без накладань.

## Розміри шрифтів

`xs`, `s`, `m` (дефолт), `l0`, `l1`, `l2`. Заголовок дошки — `l2`, розділу — `l1`, підзаголовок — `l0`, підписи — `m`/`s`.

## Макет стратегічної дошки

```
[# Назва проєкту, l2]
[Mind map: ціль → напрями]  →  [Flowchart: воронка]  →  [Таблиця: KPI]
             ↓
[Sticky notes: гіпотези]    →  [Kanban: задачі]
```
