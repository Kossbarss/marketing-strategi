# Mind map і мозкові штурми

`how_to` не потрібен — передавай `data.markdown` з відступами.

```json
create({
  "type": "mindmap",
  "title": "Контент-стратегія Q4",
  "data": {
    "layout": "horizontal",
    "markdown": "Контент-стратегія Q4\n- Instagram\n  - Reels: кейси клієнтів\n  - Каруселі: чек-листи\n- Telegram\n  - Щоденні інсайти\n  - Воронка на консультацію\n- YouTube\n  - Туторіали AI-інструментів\n- Метрики\n  - Охоплення\n  - Ліди\n  - CAC"
  }
})
```

- `layout`: `horizontal` (гілки ліворуч/праворуч, дефолт) або `vertical` (дерево зверху вниз — краще для оргструктур і ієрархій сайту).
- Корінь — перший рядок без `-`. Кожен рівень — +2 пробіли.

## Техніки мозкового штурму

| Техніка | Як будувати |
|---|---|
| **Класичний штурм** | Корінь = питання; 4–7 гілок-напрямів; по 3–5 ідей на гілку |
| **5W1H** | Гілки: Хто / Що / Де / Коли / Чому / Як |
| **SCAMPER** | Гілки: Замінити / Комбінувати / Адаптувати / Змінити / Інше застосування / Прибрати / Перевернути |
| **Проблема → причини** | Корінь = проблема; гілки = категорії причин (люди, процес, канал, продукт, гроші) |
| **Customer journey** | Гілки = етапи (усвідомлення → інтерес → рішення → покупка → лояльність), всередині — точки дотику |
| **Ніша / аудиторія** | Гілки: болі, бажання, заперечення, тригери, канали |

## Правила

- 1–5 слів на вузол. Думка довша — це нотатка, а не вузол.
- Не більше 4 рівнів. Глибше — окрема mind map, розміщена через `placement`.
- Для вибору пріоритетів після штурму — створи поруч `sticky_notes` або таблицю (ідея / вплив / зусилля).
- Редагування: `fetch` з `scope: <mindmap_id>`, потім `edit` → `find_replace` / `delete_by_text`.
