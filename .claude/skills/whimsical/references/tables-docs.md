# Таблиці і доки

Детально: `how_to('table')`, `how_to('doc')`.

## Коли що

| Потрібно | Обирай |
|---|---|
| Таблиця поруч зі схемою на дошці, кольорові статуси | **Таблиця на дошці** |
| Таблиця, яка росте (додавати рядки/колонки), контент-план, трекер | **Таблиця в доці** |
| Текст + таблиці + вкладені дошки | **Док** |

## Таблиця на дошці

Нова дошка з таблицею:
```json
create({"type": "table", "title": "Медіаплан", "data": {
  "columns": ["Канал", "Бюджет", "CPL", "Статус"],
  "rows": [["Meta", "$800", "$4.2", {"text": "Активна", "color": "green"}],
           ["TikTok", "$400", "$6.1", {"text": "Тест", "color": "yellow"}]]}})
```

На існуючій дошці — `edit` з `{"op":"add","type":"table", columns, rows, head_color, head_style, table_style, styles}`.

- Редагувати клітинки: `{"op":"update","id":"<table_id>","type":"table","cells":[{"row":1,"col":3,"text":"Стоп","color":"red","deco":"fill"}]}`. Рядок 0 — заголовок.
- **Додати рядок/колонку до таблиці на дошці не можна** — видали і створи заново з повними даними.
- Прочитати: `fetch({id: <table_id>, board_id: <board_id>})`.

## Док

```json
doc_create(...)  // або create({type:'doc', ...}) — markdown-вміст
```

Редагування (`edit` з id доку; спершу `fetch`, щоб побачити id блоків):
- `append_blocks` (markdown у кінець), `insert_after_block`, `update_block`, `delete_block`, `replace_content`
- Таблиці в доці: створюються markdown-таблицею; далі `update_cells`, `add_rows` (CSV), `remove_rows`, `add_columns`, `remove_columns`.

## Шаблони для маркетингу

- **Контент-план**: Дата | Платформа | Формат | Тема | Хук | CTA | Статус
- **Медіаплан**: Канал | Аудиторія | Бюджет | CPM | CTR | CPL | Статус
- **Тест креативів**: Креатив | Гіпотеза | Витрати | CTR | CPA | Рішення
- **Конкуренти**: Бренд | Оффер | Ціна | Канали | Сильне | Слабке
- **Пріоритизація ідей (ICE)**: Ідея | Impact | Confidence | Ease | Бал
