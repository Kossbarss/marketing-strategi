# FFmpeg — маршрутизатор монтажу

Вхідна точка для будь-якої роботи з готовими відео- та аудіофайлами. Спершу визнач задачу, потім відкрий відповідний файл у `references/`.

## FFmpeg чи Remotion

| Задача | Інструмент |
|---|---|
| Обрізати, склеїти, перекодувати, стиснути, змінити формат кадру, звук, субтитри з готового `.srt` | **ffmpeg** (цей скіл) |
| Анімована графіка, титри, моушн, караоке-субтитри, відео з даних або шаблону | **Remotion** (`remotion-best-practices`) |
| Обидва: сирий матеріал + анімована графіка | ffmpeg готує кліпи (нарізка, звук, формат) → Remotion збирає фінальний ролик |

## Правила

1. **Спершу `ffprobe`.** Не вгадуй тривалість, розмір кадру, fps чи наявність аудіодоріжки — подивись (команда нижче).
2. **Не перезаписуй вихідний файл.** Результат клади в `out/`, проміжні файли — у тимчасову теку.
3. **Точний різ потребує перекодування.** `-c copy` ріже лише по ключових кадрах і дає застиглий початок. Копіюй потоки тільки коли точність до кадру не потрібна.
4. **Сумісність за замовчуванням:** `-c:v libx264 -pix_fmt yuv420p -c:a aac -movflags +faststart`. Без `yuv420p` файл може не відкритися на телефоні чи в соцмережі.
5. **Перевір результат.** Після рендеру: `ffprobe` на вихідному файлі і кілька кадрів у PNG, які треба переглянути очима (особливо субтитри, кроп, накладки).
6. Завжди додавай `-hide_banner -y`, а в скриптах ще й `-loglevel error -stats`.

## Аналіз файлу

```bash
ffprobe -v error -show_entries format=duration,size,bit_rate:stream=index,codec_type,codec_name,width,height,r_frame_rate,sample_rate,channels -of json input.mp4
```

Кадр для перегляду на 5-й секунді:

```bash
ffmpeg -hide_banner -y -ss 5 -i input.mp4 -frames:v 1 out/frame.png
```

## Пресети платформ

| Платформа | Кадр | FPS | Тривалість | Примітка |
|---|---|---|---|---|
| Instagram Reels, TikTok, YouTube Shorts | 1080×1920 (9:16) | 30 | до 60–90 с для охоплення | Важливе тримай у центрі: зверху ~250 px і знизу ~400 px закриває інтерфейс |
| Instagram пост | 1080×1350 (4:5) або 1080×1080 | 30 | до 60 с | |
| YouTube | 1920×1080 (16:9) | 25/30/60 | — | Гучність −14 LUFS |
| LinkedIn, Facebook стрічка | 1080×1080 або 1920×1080 | 30 | 30–90 с | Субтитри обовʼязкові: дивляться без звуку |
| Telegram | будь-який, краще ≤ 1280 px | 30 | — | До 50 МБ через бота, стискай |

Ліміти платформ змінюються — перед здачею клієнту звір з актуальними вимогами.

## Інструменти

| Інструмент | Для чого | Наявність |
|---|---|---|
| `ffmpeg`, `ffprobe` | Вся обробка відео й аудіо | Потрібно встановити: `apt install ffmpeg` / `brew install ffmpeg` |
| `convert` (ImageMagick) | Обкладинки, ресайз і склейка зображень | `apt install imagemagick` |
| `yt-dlp` | Завантажити відео за посиланням | `pip install yt-dlp` |
| `faster-whisper` | Транскрипція в `.srt` | `pip install faster-whisper`, модель качається з Hugging Face |

Перед використанням перевір `which ffmpeg ffprobe convert yt-dlp`. Якщо в проєкті є Remotion, ffmpeg доступний і без встановлення: `npx remotion ffmpeg`, `npx remotion ffprobe`.
