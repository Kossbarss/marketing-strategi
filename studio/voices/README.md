# Закадрові голоси

Мета: взяти закадровий голос із наданого відео і озвучити ним **новий** текст для іншого відео, зберігши тембр, інтонації та манеру. Дозволи й ліцензії на голоси має замовник (підтверджено 2026-11-14).

## Де що лежить

- **Аудіо** — Google Drive, `Studio/05_Voices/<назва_голосу>/`:
  - `source/` — відео або аудіо, з якого взято голос;
  - `samples/` — чисті фрагменти голосу без музики (зразок для клонування);
  - `output/` — згенерована озвучка.
- **Опис голосу** — тут, `studio/voices/<назва_голосу>/profile.md`: мова, стать, темп, манера, джерело, точний текст зразка.

## Стан (2026-11-14)

Інструмент клонування **не протестовано**; основний кандидат — OmniVoice. Жодного голосу ще не додано.

Мови озвучки (від замовника): українська, російська, чеська, словацька, польська, португальська, англійська (США, Велика Британія, Ірландія) та інші.

Обмеження компʼютера замовника: Intel Core i7-4710HQ, без потужної відеокарти — моделі працюватимуть лише на процесорі, повільно.
